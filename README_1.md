# KEITH

Network is net worth. A voice companion that interviews you about the people who shaped you, keeps them as cards, and tells you who to ping today.

Runs entirely in the browser. Your data stays on your device (export a backup from the top right).

## Run it
Open `index.html` in Chrome or Safari, or host the folder anywhere static (GitHub Pages works).

## Optional
Add a Claude API key in Settings to get the real Keith: natural conversation, automatic people extraction, drafted messages in your voice, and web lookup for professional contacts.
